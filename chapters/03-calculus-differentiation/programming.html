6.0.1 Data Structures (continued)

6.0.1.1 Factors

Factors are used for categorical data - both nominal and ordinal ones.

Factors are a special form of vectors:

  • Each element corresponds to a value from a set known as a factor’s levels.
  • A factor’s levels are stored in a specific order.

You can define a factor by using factor() command.

For example, we have a variable measuring dose of vaccine administered (placebo, medium, high) in two waves of experiment.

Code 
vec_1 <- c("High", "Medium", "Medium", "High", "High","Placebo","Placebo")

fct_1 <- factor(vec_1)

# Notice the difference in outputs

vec_1
[1] "High"    "Medium"  "Medium"  "High"    "High"    "Placebo" "Placebo"
Code 
fct_1
[1] High    Medium  Medium  High    High    Placebo Placebo
Levels: High Medium Placebo
Code 
# i.e., `factor()` creates a vector that contains two levels: "no" and "yes"

class(fct_1)
[1] "factor"
Code 
class(vec_1)
[1] "character"

Since these experiments were conducted in two waves. It could be of interest to denote the no. of wave for each experiment.

Code 
# Btw, table() command cn be used in R for cross-tabulations
table(vec_1)
vec_1
   High  Medium Placebo 
      3       2       2
Code 
table(fct_1)
fct_1
   High  Medium Placebo 
      3       2       2
Code

table(fct_1, fct_2)

  Medium      0     2

Ordering Factors

Sometimes it is essential to specify the orders of your factor levels. Particularly during modelling and estimation with binary or categorical variables, given that the first level of factor is used in most functions, like lm(linear regression command in R), will be treated as baseline level or category.

We use levels() within factor() command to do this.

Code 
# Order is often determined using alphabetical variables by default) (H-M-P)

# Ordering it
fct_3 <- factor(c("High", "Medium", "Medium", "High", "High","Placebo","Placebo"),
levels = c("Placebo","Medium","High"))

fct_3
[1] High    Medium  Medium  High    High    Placebo Placebo
Levels: Placebo Medium High

6.1 Conditionals in Base R

Conditional statements let your code make decisions.

6.1.1 Comparison operators (what they do)

  • ==, !=: test equality / inequality (return TRUE/FALSE).
  • >, >=, <, <=: numeric comparisons.
  • &, |: logic operators
  • !: logical negation.
Code 
x <- 10
y <- 20

x == y     # FALSE
[1] FALSE
Code 
x != y     # TRUE
[1] TRUE
Code 
x > 0      # TRUE
[1] TRUE
Code 
x >= 10    # TRUE
[1] TRUE
Code 
x < y      # TRUE
[1] TRUE
Code 
x <= y     # TRUE
[1] TRUE

6.1.2 if

  • Runs a code block only if the condition is TRUE.
Code 
if (x > 0) {
  print("x is a positive number")
}
[1] "x is a positive number"

6.1.3 if ... else

  • Chooses one of two paths.
```{r}
if (x > y) {
  print("x is greater than y")
} else {
  print("y is greater than or equal to x")
}
```

6.1.4 Laddered else if

  • Chains multiple mutually exclusive tests.
Code 
# condition 1
x <- 10
y <- 20
# condition 2
x <- y

# test
if (x > y) {
  print("x is greater than y")
} else if (y > x) {
  print("y is greater than x")
} else {
  print("x and y are equal")
}
[1] "x and y are equal"

6.1.5 Nested if

  • Scope one decision inside another.
Code 
x <- 20; y <- 10; z <- -30

if (x > y) {
  print("x is greater than y") #decision 1 if x>y
  if (x > z) {                 #decision 2 if x>y
    print("x is greater than y and z")
  }
}
[1] "x is greater than y"
[1] "x is greater than y and z"

6.1.6 Multiple conditions and &/| `

Code 
#one number

Code 
#Vectors

## Programming Session - Day 3 {#sec-03-programming}

### Data Structures (continued)

#### Factors

Factors are used for categorical data - both nominal and ordinal ones.

Factors are a special form of vectors:

* Each element corresponds to a value from a set known as a factor's levels.
* A factor's levels are stored in a specific order.

::: callout
You can define a factor by using `factor()` command.

For example, we have a variable measuring dose of vaccine administered (placebo, medium, high) in two waves of experiment. 

```{r}
vec_1 <- c("High", "Medium", "Medium", "High", "High","Placebo","Placebo")

fct_1 <- factor(vec_1)

# Notice the difference in outputs

vec_1

fct_1
# i.e., `factor()` creates a vector that contains two levels: "no" and "yes"

class(fct_1)
class(vec_1)
```

Since these experiments were conducted in two waves. It could be of interest to denote the no. of wave for each experiment. 

```{r}
# Btw, table() command cn be used in R for cross-tabulations
table(vec_1)
table(fct_1)

fct_2 <- factor(c("Run 1", "Run 2", "Run 2", "Run 1", "Run 2","Run 1","Run 2"))

table(fct_1, fct_2)            

```

## Conditionals in Base R

Conditional statements let your code make decisions.

### Comparison operators (what they do)

-   `==`, `!=`: test equality / inequality (return TRUE/FALSE).
-   `>`, `>=`, `<`, `<=`: numeric comparisons.
-   `&`, `|`: logic operators
-   `!`: logical negation.

```{r}
x <- 10
y <- 20

x == y     # FALSE
x != y     # TRUE
x > 0      # TRUE
x >= 10    # TRUE
x < y      # TRUE
x <= y     # TRUE
```

### `if`

-   Runs a code block **only if** the condition is TRUE.

```{r}
if (x > 0) {
  print("x is a positive number")
}
```

### `if ... else`

-   Chooses **one** of two paths.

```{r}
if (x > y) {
  print("x is greater than y")
} else {
  print("y is greater than or equal to x")
}
```

### Laddered `else if`

-   Chains multiple mutually exclusive tests.

```{r}
# condition 1
x <- 10
y <- 20
# condition 2
x <- y

# test
if (x > y) {
  print("x is greater than y")
} else if (y > x) {
  print("y is greater than x")
} else {
  print("x and y are equal")
}
```

### Nested `if`

-   Scope one decision **inside** another.

```{r}
x <- 20; y <- 10; z <- -30

if (x > y) {
  print("x is greater than y") #decision 1 if x>y
  if (x > z) {                 #decision 2 if x>y
    print("x is greater than y and z")
  }
}
```

### Multiple conditions and `&`/`|` `

```{r}
#one number
x <- 5
y <- 3
z <- 1

x > y & x > z


#Vectors

x <- c(10, 50, 30)
y <- c(6, 40, 15)
z <- c(12, 35, 40)

x > y 
y > z

x > y & y > z
```

## Descriptive Statistics & Aggregation (Base R)

Summarize the [`mpg` dataset](https://rpubs.com/shailesh/mpg-exploration) to understand central tendency, spread, and relationships.

### Central tendency

-   `mean(x)`: arithmetic average (sensitive to outliers).
-   `median(x)`: middle value (robust to outliers).

```{r}
#| message: false
# Install if needed (run once):
#install.packages("ggplot2")
library(ggplot2)   # loads ggplot2, dplyr, tidyr, readr, tibble, stringr, forcats, purrr
```

```{r}
summary(mpg)
mean(mpg$displ)
median(mpg$displ)

# Note: base R's mode() returns the storage mode, not the statistical mode.
mode(mpg$displ)
```

### Spread & quantiles

-   `var(x)`, `sd(x)`: variance and SD.
-   `quantile(x, p)`: p-th quantile (e.g., 0.25 = Q1).
-   `IQR(x)`: Q3 - Q1.
-   `range(x)`, `min(x)`, `max(x)`.

```{r}
var(mpg$cty)
sd(mpg$cty)

quantile(mpg$cty, c(0.25, 0.75))
IQR(mpg$cty)

min(mpg$cty); max(mpg$cty)
range(mpg$cty)
```

### Categorical summaries

-   `table(x)`: counts by category.
-   `unique(x)`: distinct values.

```{r}
table(mpg$fl)
unique(mpg$cyl)
```

### Group-wise means (manual vs. `aggregate()`)

-   `aggregate(y ~ g, FUN, data)`: summary of y by groups g.
-   `subset =` lets you compute summaries on filtered rows.

```{r}
# Manual subsetting (repetitive)
mean(mpg$cty[mpg$cyl == 4])
mean(mpg$cty[mpg$cyl == 6])
mean(mpg$cty[mpg$cyl == 8])

# Using aggregate(): dv ~ iv
aggregate(cty ~ cyl, FUN = mean, data = mpg)

# Subset argument
aggregate(cty ~ cyl,
          FUN = mean,
          subset = cty < 15,
          data = mpg)
```

### Quick summaries (`summary()`, `by()`)

-   `summary(df)` gives per-column summaries.
-   `by(df, group, summary)` applies `summary()` within each group.

```{r}
summary(mpg)
summary(mpg$displ)

by(mpg, mpg$cyl, summary)
```
